# 23:17，值班室

一款可以在浏览器里离线玩的中文短篇推理游戏。第一关《迟到的三声铃》发生在虚构的石溪站。一名刚接班的值班员，要用桌上的三份记录解释眼前的矛盾。目标试玩时长约五分钟，以首次盲玩的实际体验为准。

## 开始试玩

下载仓库并解压，用现代浏览器打开根目录的 `index.html`。无需安装依赖。点击桌上的物件查看记录，可以反复翻阅，再用“写下判断”提交你的解释和两份证据。键盘可用 Tab 选择、Enter 激活、Esc 关闭弹窗。

## 第一轮怎么合作

先请一位没听过谜底的人独立试玩。请 TA 记住第一个点开的物件，以及哪一刻产生或改变了判断。可以在 GitHub Issues 留下这两句话，再补一句最困惑的地方。涉及谜底时请在标题标注「含剧透」。

每轮挑一个最影响理解或乐趣的问题，在一个分支里修改，用一个 PR 写明改了哪段体验、怎样试玩。默认分支保留可玩的版本。

## 实现与下一步

第一版使用一个 HTML 文件。三个 `template` 保存线索原文，`assess` 处理解释与证据组合的反馈。一次误判后可以保留选项并返回桌面取证。

第一轮想验证的是玩家能否靠自己的观察把两份记录对起来，以及找出答案时是否有趣。如果大家看得懂却觉得像做题，下一轮优先改证据操作，例如允许把两张纸并排比对。如果大家想亲手翻柜子，再试做一个 Three.js 柜门交互。所有人物、站点和记录均为虚构。
