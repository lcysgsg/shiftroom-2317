# 23:17，值班室

一款可以在浏览器里离线玩的中文短篇推理游戏。第一关《迟到的三声铃》发生在虚构的石溪站。一名刚接班的值班员，要用桌上的三份记录解释眼前的矛盾。目标试玩时长约五分钟，以首次盲玩的实际体验为准。

## 开始试玩

[打开在线值班室](https://lcysgsg.github.io/shiftroom-2317/)。拖动值班室可以转动视角，靠近记录仪后左右拖动摇柄，让纸带退回有刻痕的位置。压下取样杆收齐三张现场记录，再重放终端的三声铃。右上角可以开启声音。

键盘可用方向键调整模型视角或移动纸带，也可以用“倒到上一道刻痕”单步操作。展开“翻阅纸面档案”可使用原来的推理玩法。离线试玩请下载并解压整个试玩分支，再打开根目录的 `index.html`。

## 第一轮怎么合作

先请一位没听过谜底的人独立试玩。请 TA 记住第一个点开的物件，以及哪一刻产生或改变了判断。可以在 GitHub Issues 留下这两句话，再补一句最困惑的地方。涉及谜底时请在标题标注「含剧透」。

每轮挑一个最影响理解或乐趣的问题，在 PR 里写明改了哪段体验、怎样试玩。固定的在线入口跟随 `gh-pages` 发布分支自动更新。

## 实现

`room.js` 用三维顶点、正交投影和 Canvas 2D 绘制剖面模型，贴图在浏览器里生成。`recorder.js` 把摇柄、走纸、取样、铃声和灯光连起来。记录仪和纸面档案读取同一份线索数据。所有人物、站点和记录均为虚构。
